# Monika Nirala — Music Portfolio

The portfolio runs as a React application powered by Vite. The original portfolio markup and its interactive Studio behavior are preserved in `public/portfolio-template.html` and are mounted by the React app.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The current project was started at `http://127.0.0.1:5174/`.

## Production build

```sh
npm run build
npm run preview
```

## Portfolio Studio

At the bottom of the page choose **Artist login**. The first visit on a browser lets you set a local Studio passcode. It is a convenience lock for this device, not secure online authentication.

Studio can edit the profile and contact details, add or remove performance videos, original songs, music links, confirmed events, achievements, spotlight items, and gallery media. Export a JSON backup to transfer edits to another browser; import it there to restore them. Edits are saved only in the current browser and do not publish or sync to other visitors.
